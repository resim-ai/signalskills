```python
import h5py

def read(path, datasets):
    with h5py.File(path, "r") as f:
        return {name: f[name][()].tolist() for name in datasets}
```

- List what's there first: `f.visit(print)`. Datasets can be huge — slice (`f[name][::k]`) instead of loading everything for a low-res pass.
- Attributes (`f[name].attrs`) often hold units and the time base; record them in the brief.
- `.tolist()` turns numpy into plain Python for `emit_series`.
