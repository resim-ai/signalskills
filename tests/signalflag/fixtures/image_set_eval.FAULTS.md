# image_set_eval: planted faults

Not copied into workspaces (it sits next to the fixture dir, not inside it). Generated by
`tools/make_fixtures.py image_set_eval`; the numbers below are reproducible (byte-identical regeneration).

Set: 240 images (dashcam_a 90, dashcam_b 90, warehouse_cam 60), 721 labeled boxes. Conditions: day 145, night 59,
fog 36 images (warehouse_cam has no fog). Size buckets use COCO areas in label pixels (960x640): small < 32^2,
medium < 96^2, large >= 96^2. Numbers below: `eval.py` matching (same class, IoU >= 0.5, greedy by score) at
score >= 0.5 unless noted. Recall is bucketed by GT box, precision by predicted box.

## Everything else

Background FP rate: Poisson 0.6/image (v4.1) and 0.4/image (v4.2), score ~ N(0.30, 0.15). Night is x0.90 (v4.1) and
x0.93 (v4.2). Box jitter is 6% per edge for both versions. eval.py prints only the overall and per-class numbers, so the
condition, size, source and label-error findings need extra slicing (meta.csv + labels).
